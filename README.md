# 🌤️ SkyFy Weather Data

A simple weather application built using HTML, CSS, JavaScript, Node.js and Express.

## ✨ Features

- 🌡️ Current temperature
- 💧 Humidity
- 💨 Wind speed
- 📅 5-day forecast
- 📍 Current location weather
- 🔍 Search weather by city
- 📱 Responsive design

## 🛠️ Technologies

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- OpenWeather API

## ⚙️ How to Run

```bash
npm install
node server.js
